Jugadores

Cada persona que juegue en este dispositivo puede tener su propio nombre. Al armar una partida asignás quién controla cada bando, y en los turnos se muestra de quién es cada uno.

Multijugador

En este dispositivo

Dos o más personas turnándose con el mismo celular o computadora. Entre turno y turno aparece una pantalla de relevo para que nadie vea lo del otro.

En línea

Cada uno desde su dispositivo, con una sala de código corto. La partida se sincroniza turno a turno y cada jugador ve solo lo que le corresponde.

Tus partidas en línea

Las salas en las que estás siguen guardadas en el servidor. Entrá cuando quieras: la partida espera a que estén todos y sigue donde quedó.

Sala

Cerrar el modo de prueba

El modo de prueba vence a los 30 días y mientras tanto cualquiera puede leer y escribir toda la base. Para cerrarlo: entrá a Realtime Database → pestaña Reglas, borrá lo que haya y pegá esto, después Publicar.

{
  "rules": {
    "salas": {
      ".read": true,
      "$sala": {
        ".write": true,
        ".validate": "newData.hasChildren(['estado','slots']) || !newData.exists()",
        "estadoJuego": { ".validate": "newData.isString() && newData.val().length < 400000" }
      }
    },
    "usuarios": {
      "$user": {
        ".read": true,
        ".write": "!data.exists() || (newData.exists() && newData.child('claveHash').val() === data.child('claveHash').val())",
        ".validate": "newData.hasChildren(['nombre','claveHash']) || !newData.exists()"
      }
    },
    "estadisticas": {
      "partidas": {
        ".read": true,
        "$id": {
          ".write": "!data.exists()",
          ".validate": "newData.hasChildren(['mapa','facciones','ganadores','turnos'])"
        }
      }
    },
    "$otro": { ".read": false, ".write": false }
  }
}

Con estas reglas solo se pueden crear y leer salas y usuarios: nadie puede escribir en otra parte de tu base. Un usuario nuevo se puede crear libremente, pero una vez creado solo se puede modificar si se manda el mismo hash de clave que ya tenía guardado — así nadie te pisa la cuenta sin saber tu clave. Ojo: esto no es un banco; el hash de la clave queda legible en la base para poder validar el inicio de sesión sin un servidor propio. Alcanza para frenar a un curioso, no a alguien decidido con acceso a tu base.

Usar otro proyecto

  1. console.firebase.google.com → crear proyecto.
  2. Compilación → Realtime Database → Crear base de datos.
  3. Engranaje → Configuración del proyecto → Tus apps → icono web </>.
  4. Copiá el bloque firebaseConfig y pegalo acá al lado.
  5. Guardá y pegá también las reglas de arriba.

Rendimiento

El juego mide cómo corre y ajusta los efectos del mapa solo.

Reiniciar la aplicación

Si algo queda trabado: borra la caché y los datos guardados en este dispositivo y vuelve a cargar todo de cero. Tu cuenta en la nube y su progreso no se tocan. También está el botón ⟲ abajo a la izquierda en todas las pantallas, o podés agregar ?reset=1 al final de la dirección del juego.

Pistas para empezar

Avisos cortos la primera vez que hacés cada cosa (seleccionar, atacar, reclutar, tomar una aldea, cambio de jornada, niebla). Cada uno aparece una sola vez.

Voces en los diálogos

Un toque de sonido distinto por facción cada vez que un personaje habla.

Aviso cuando te toca (en línea)

Vibración y notificación cuando llega tu turno en una sala en línea y la app está de fondo. La primera vez pide permiso al entrar a una sala.

Balance con partidas reales

Al terminar una escaramuza con personas, se registra anónimamente qué facción ganó y en qué mapa (sin nombres). Así el balance se mide con gente, no con simulaciones.

Cargando…

Sonidos del día

Un sonido corto al cambiar la jornada: gallo al amanecer, chicharras al mediodía, pájaros a la tarde, lechuza al atardecer, grillos de noche y viento en la noche cerrada.

Mantener la pantalla encendida

La pantalla se queda encendida mientras estás en una partida.

Orientación de la pantalla

Por defecto todo el juego va en apaisado (horizontal), menús incluidos. Podés cambiarlo a vertical o automático. Necesita pantalla completa: funciona mejor con el juego instalado como app. También está el botón ⟳ en la barra.

Instalar en el dispositivo

Queda como una app más, a pantalla completa y con su icono. Abre sin conexión; el multijugador sí necesita internet.

Tamaño de los hexágonos

Seguir los combates con la cámara

Durante el turno de la IA, el tablero se desplaza solo hacia cada ataque.

Minimapa

Un mapa chico en la esquina del tablero. Tocalo o arrastralo para saltar a esa zona.

Pantalla completa

Solo en la versión instalada. También podés alternar con la tecla F11.

Desplazar por los bordes

En computadora: al acercar el mouse al borde del tablero, el mapa se mueve solo hacia ese lado. Cuanto más cerca del borde, más rápido.

Rueda del ratón

Qué hace la rueda sobre el tablero. Por defecto hace zoom; para mover el mapa, agarralo con el botón izquierdo y arrastralo. Con "desplazar", el zoom se hace con Ctrl + rueda o con los botones + y −.

Ambiente animado

Brillo en el agua, humo en las aldeas ocupadas y sombras de nubes cruzando el mapa. Desactivalo si el dispositivo se calienta.

Avisar al terminar el turno

Si quedan unidades sin mover, pide un segundo toque en "Terminar turno".
